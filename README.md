A tiny, deterministic program for the make.fun competition
"The Vacuum's Alibi: One Line, 200 Characters".

It writes exactly one line — a robot vacuum's excuse for missing a
spot — to `/output/entry.txt`:

> I did not miss that corner. My sensors mapped it, my schedule
> respected it, and my battery and I agreed: that is where the spider
> pays rent, and I do not do evictions.

The program checks the gate's 1–200 character limit itself before
writing. No network, no randomness: every run produces the same file,
byte for byte.

Run it with Node:

```sh
node main.ts
OUTPUT_DIR=./out node main.ts
```
